# Badge VFX Frames

These transparent PNG sequences are generated by `tools/generate_badge_vfx.py`.
They are lightweight runtime badge overlays built from normalized material
sprites, not live Qt line drawing.

Pipeline:
1. CC0 source sheets live in `tools/vfx_source_sheets`.
2. `tools/elemental_vfx_assets.py` slices and normalizes those source sheets
   into material sprites in `assets/images/vfx_materials`. If the source sheets
   are missing, it falls back to local procedural material sprites.
3. `tools/generate_badge_vfx.py` composites those material sprites into the final
   per-badge frame sequences in `assets/images/badge_vfx`.
4. `frontend/badge_effects.py` only plays the completed frame sequences at
   runtime.

Current art direction:
- Avoid traveling diagonal shine/sweep bars; they read as distracting UI chrome.
- Badge art is the hero. VFX should feel like ambient loadout/splash-art life,
  not an ability cast.
- Prefer short micro-events with quiet gaps: one tiny lightning spark, a few
  embers, a soft vapor breath, a small drip, a dust crumble, or a brief glint.
- Do not anchor a badge's effect to only one edge. Each badge animation loop
  should schedule subtle events from at least three different sides with calm
  intervals between them.
- Avoid always-on auras, full-badge explosions, large centered clouds, and
  anything that keeps moving loudly while the user is trying to read the UI.
- Lines, sparks, dots, cracks, and orbit marks are allowed only as brief accents
  after the badge's theme is already clear.
- Keep the motion readable in the tiny equipped-badge slot without covering the
  achievement artwork.
- Each achievement badge should have its own named VFX folder. Families may
  share source material sprites, like a normal game VFX atlas, but the final
  badge recipe should vary the material mix, timing, scale, drift, and accent.
- The current pass follows a cinematic splash/loadout structure inspired by
  modern game VFX references: anchored source point, readable elemental
  silhouette, brief impact beat, and lingering residue. Do not copy external
  artwork or frames.

Design references used:
- Riot Games League VFX Style Guide: clarity, low visual noise, theme, timing.
- OpenGameArt CC0/usable special-effect spritesheet listings for game VFX asset
  structure and looping-frame conventions.
- Behance VFX/splash animation references shared during review:
  Fire/Lightning Ultimate VFX Hero Wars and League of Legends Login Screen
  Animations (2017).

To regenerate:

```powershell
python -B tools\generate_badge_vfx.py
```

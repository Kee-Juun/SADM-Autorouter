# VFX Material Sprites

These transparent PNGs are normalized build output for achievement badge
animations. They are generated by `tools/elemental_vfx_assets.py`, which prefers
the CC0 source sheets in `tools/vfx_source_sheets` and falls back to local
procedural sprites if those files are missing.

`tools/generate_badge_vfx.py` then composites these normalized sprites into the
final frame sequences under `assets/images/badge_vfx`.

Do not edit generated sprite frames by hand unless you are intentionally doing
an art override. For repeatable changes, adjust `tools/elemental_vfx_assets.py`
or the CC0 source sheets in `tools/vfx_source_sheets`, then rerun:

```powershell
python -B tools\generate_badge_vfx.py
```
